# Task 1 — Language Translation Tool

## Features
- Source and target language selection
- Translation through the MyMemory translation API
- Clear result display and copy button
- Basic input and network error handling

## Run
From this folder:
```bash
pip install -r ../requirements.txt
python app.py
```
Open the local address printed by Flask (usually http://127.0.0.1:5000).

## Demo ideas
1. Translate “Good morning” from English to Hindi.
2. Try English to Telugu.
3. Show the copy button and empty-input validation.

The translation service is external and may have usage limits or return imperfect translations. Do not enter private or sensitive text.
