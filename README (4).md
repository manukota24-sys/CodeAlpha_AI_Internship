# CodeAlpha AI Internship — Two Tasks

This package contains two beginner-friendly projects:
1. Language Translation Tool
2. FAQ Chatbot using NLP similarity matching

## Requirements
- Python 3.10+
- Internet connection for the Translation Tool's MyMemory API
- FAQ Chatbot runs locally after dependencies are installed

## Setup
Open a terminal in the project folder and install dependencies:
```bash
pip install -r requirements.txt
```

Each task is in its own folder. Follow that folder's README.

Important: Test both projects on your own computer, customize the UI/data, and record your own demo before submitting. Follow CodeAlpha's official submission form and rules.
